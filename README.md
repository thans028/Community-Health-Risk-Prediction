# Community-Health-Risk-Prediction
Used Python, pandas, and CDC PLACES county-level data to explore community health indicators, analyze public health trends, and develop a foundation for predictive health risk analysis.

## Dataset
- Source: CDC PLACES 2025
- Records: 2,956 county-level records
- Target variable: Diabetes prevalence

## Tools & Technologies
- Python
- Pandas
- Scikit-learn
- Linear Regression

## Methodology
1. Loaded and explored the CDC PLACES dataset.
2. Examined community health indicators, including obesity, smoking, physical inactivity, high blood pressure, heart disease, and stroke.
3. Used these indicators as input variables for a Linear Regression model.
4. Evaluated model performance using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R².
